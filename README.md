# ⚔️ رِجَالٌ صَدَقُوا | درع العفة وسباق الصادقين
> **«مِّنَ الْمُؤْمِنِينَ رِجَالٌ صَدَقُوا مَا عَاهَدُوا اللَّهَ عَلَيْهِ»**

منظومة إيمانية ونفسية ذكية وتطبيق مصغر في تليجرام (**Telegram Mini App**) صُممت لكسر قيد الإباحية والعادة السرية، واستبدال الدوبامين المسموم بنور الإيمان وعزة الرجولة والتنافس الشريف في الصمود وطاعة الله.

---

## 🌟 الميزات الأساسية (المرحلة الأولى - MVP)

1. **درع العفة وعداد الصمود المباشر (Purity Streak Counter):**
   * عداد رقمي فخم بالأيام والساعات والدقائق والثواني.
   * رتب إيمانية تصاعدية (تائب مقبل 🌱، صابر مجاهد ⚔️، مرابط ثابت 🛡️، قاهر الشهوة 🦅، فارس العفة 👑، صِدِّيق 🌟).
   * شريط التقدم نحو الرتبة التالية مع نقاط الشرف.

2. **لوحة البطولة والشرف (Hall of Fame & Leaderboard):**
   * منصة تتويج للأبطال الثلاثة الأوائل 🥇🥈🥉.
   * ترتيب المتنافسين حسب الصمود الحالي وأطول صمود تاريخي.
   * إمكانية اختيار اسم مستعار أو لقب لحفظ الستر والخصوصية.

3. **زر الاستغاثة والطوارئ (SOS Panic Protocol):**
   * بروتوكول تدريجي يبدأ بكسر شعلة الدوبامين (تمرين تنفس 4-7-8 مع عداد زمني).
   * صدمة استحضار مراقبة الجبار: «أَلَمْ يَعْلَم بِأَنَّ اللَّهَ يَرَى».
   * أوامر نجاة صارمة وفورية: ترك الهاتف، الوضوء بماء بارد، ركعتين خاشعتين.
   * زر «نجوت بفضل الله» لاحتساب نصر جديد وإضافة نقاط شرف.

4. **خارطة تعافي الدماغ وكيمياء الدوبامين (Dopamine Reset):**
   * جدول علمي وإيماني تفاعلي يوضح ماذا يحدث في الدماغ في اليوم 1، 3، 7، 14، 30، 60، 90.

5. **المساءلة اليومية (Daily Check-in):**
   * توثيق الثبات اليومي بنقرة واحدة مع زاد يومي من القرآن والحديث.

6. **بوت تليجرام متكامل (@rejal313bot):**
   * استقبال أوامر `/start`, `/sos`, `/streak`, `/leaderboard`, `/checkin`.
   * أزرار تفاعلية وشاشات مدمجة.

## 🚀 خطوات التشغيل والربط

### 1. إنشاء جداول قاعدة البيانات في Supabase (ثانيتان فقط):
1. افتح مشروعك في [Supabase Dashboard](https://supabase.com/dashboard/project/enlabmxseafcjbhfigqj).
2. من القائمة الجانبية، اضغط على **SQL Editor**.
3. انسخ محتوى الملف `supabase/schema.sql` والصقه في المحرر.
4. اضغط على زر **Run** الأخضر.
*(سيتم إنشاء جداول profiles, checkins, relapses, sos_logs, daily_wisdoms فوراً).*

---

### 2. التجربة المحلية (Local Testing):
لتشغيل واجهة التطبيق المصغر:
```bash
npm run dev
```
سيعمل على الرابط: `http://localhost:3000`

لتشغيل بوت التليجرام محلياً لتجربته فوراً:
```bash
npm run bot
```
افتح تليجرام واكتب للبوت `@rejal313bot` الأمر `/start` وستجد البوت يرد عليك مباشرة!

---

### 3. النشر على Vercel (في دقيقة واحدة):
1. ارفع المشروع إلى حسابك في **GitHub**:
```bash
git add .
git commit -m "feat: initial release of Rejal Sadako platform"
git remote add origin https://github.com/YOUR_USERNAME/rejal-sadako.git
git push -u origin main
```
2. ادخل على [Vercel](https://vercel.com)، واضغط **Add New Project** واختر المستودع.
3. أضف متغيرات البيئة (Environment Variables) الموجودة في `.env.local`.
4. اضغط **Deploy**!

---

### 4. ربط Webhook وتفعيل زر التطبيق في BotFather:
1. بعد النشر والحصول على رابط Vercel (مثال: `https://rejal-sadako.vercel.app`)، شغّل:
```bash
node scripts/set-webhook.mjs https://rejal-sadako.vercel.app
```
2. في تليجرام، افتح `@BotFather`:
   * أرسل `/mybots` واختر `@rejal313bot`.
   * اضغط **Bot Settings** -> **Menu Button** -> **Configure menu button**.
   * أرسل رابط التطبيق على Vercel: `https://rejal-sadako.vercel.app`.
   * اكتب عنوان الزر: `⚔️ درع العفة`.
   * الآن سيظهر زر فتح التطبيق بجانب حقل الكتابة في تليجرام لكل مستخدم!
